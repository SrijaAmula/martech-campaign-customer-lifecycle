# BA Frameworks

## SWOT
**Strengths:** available transaction/event data; executive sponsorship. **Weaknesses:** inconsistent definitions; manual handoffs. **Opportunities:** automation, self-service analytics, journey optimization. **Threats:** data quality, adoption resistance, privacy/security risk.

## PESTLE prompts
Political/regulatory, economic conditions, social/customer behavior, technology/platform changes, legal/privacy obligations, environmental/operational impacts.

## Root Cause
**Five Whys:** KPI mismatch → different formulas → no glossary owner → decentralized reporting → no governance. Root cause: missing metric governance.

**Fishbone categories:** People, Process, Technology, Data, Policy, Measurement.

## Prioritization
MoSCoW used with business value, risk, dependency, effort and regulatory/control needs.
